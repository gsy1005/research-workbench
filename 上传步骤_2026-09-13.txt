【一、上传（10 分钟）】

方案 A · 直接网页上传（推荐，一直用的方法）
1. 解压 research-workbench_完整版_2026-09-13.zip
2. 浏览器打开 https://github.com/gsy1005/research-workbench
3. 进入解压出来的 research-workbench-upload-root 文件夹
   （注意：zip 里的「上传步骤」「数据补全清单」两个说明文档、
    以及「内部备份_勿上传」整个文件夹，都在上传文件夹外面，
    不要传上去，只给自己看）
   ※ 本次起 lib 里 6 个核心逻辑文件已做防抄混淆（外人看到的是乱码，
    只能仿外观、抄不动判断逻辑）；可读原版在「内部备份_勿上传」里
4. 网页右上角 Add file → Upload files → 把文件夹里的文件和文件夹
   全部拖进去 → 页面底部 Commit changes（绿色按钮）
   ※ 如果网页不让上传 .github 文件夹（部分浏览器不识别点开头的文件夹），
     就跳过它，单独用方案 B 处理下面这条 ↓
   ※ .github/workflows/daily_data.yml 有更新（合并了预测市场抓取）：
     仓库里依次点开 .github → workflows → daily_data.yml → 右上角铅笔 →
     全选删除 → 粘贴本地 .github/workflows/daily_data.yml 全文 → Commit
5. 等 1~3 分钟，打开你的网站，强刷（Ctrl+F5）

方案 B · 网页覆盖单个文件
   仓库里点开同名文件 → 右上角铅笔（Edit）→ 全选删除旧内容 →
   粘贴本地新文件全文 → Commit changes。适合只改一两个文件时。

【二、上传后去 Actions 手动跑一次管线】
1. 仓库顶部点 Actions
2. 左侧选 daily_data.yml（或 release.yml / fedwatch.yml）
3. 右侧出现「Run workflow ▾」灰色按钮 → 点它 → 弹框里再点绿色 Run workflow
4. 约 3 分钟后数据即最新
※ 只有刚传完新代码才需要手动点这一次。平时什么都不用点——
  左侧那 8 个工作流全部是按时间表自动运行的（见【五】）。

【五、左侧 8 个工作流说明（都不用手动跑）】
· daily_data.yml     每天 07:40 / 20:40（北京）自动：宏观+日历+特朗普+预测市场+出图
· release.yml        工作日 21:45 + 次日 09:45 自动：CPI/PCE/GDP/非农等发布日专抓
· fedwatch.yml       工作日每 2 小时自动：CME 加息降息概率
· live_quotes.yml    工作日每 2 小时 + 周日自动：盘中行情快照
· refresh.yml        每 30 分钟自动：新闻快讯
· truths.yml         美国白天每小时自动：特朗普社媒
· polymarket.yml     每天 09:05 自动（本次已合并进 daily_data.yml，
                     可删可不删，留着无害；想删：仓库点开该文件 → 右上 ⋯ → Delete file）
· diag.yml           仅手动排查用，平时无视
结论：不需要每天手动跑。只有上传了新代码后，按【二】手动触发一次即可。
